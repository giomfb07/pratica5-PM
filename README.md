# Sistema de Pedidos - Prática 5 (JUnit)

Projeto Maven (Java 17+, JUnit 5).

- Rodar testes: `mvn test`
- NetBeans/IntelliJ/Eclipse: abra como projeto Maven existente.
- Sem Maven: adicione o JUnit Jupiter (API + Engine) às bibliotecas do projeto.

Regras: Eletrônico -10%, Físico +10% (frete), Expresso +20% (urgência).
Pedido ENTREGUE não pode ser alterado (StatusInvalidoException).
